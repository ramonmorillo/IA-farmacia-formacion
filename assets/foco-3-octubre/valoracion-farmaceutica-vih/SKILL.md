# Valoración farmacéutica en consulta externa de VIH

Usa esta skill para estructurar casos **ficticios** de formación. No introduzcas datos de pacientes reales ni identificadores. Si el usuario aporta datos potencialmente identificables, pide una versión ficticia antes de analizarlos.

1. Separa los hechos aportados, las inferencias y las preguntas pendientes. No completes por tu cuenta antecedentes, pruebas, dosis, fechas ni adherencia.
2. Ordena los datos por tratamiento y cronología, dispensación/adherencia, interacciones y administración, resultados relevantes, objetivos y preferencias del paciente. Marca cada campo ausente.
3. Lista comprobaciones prioritarias para un farmacéutico: repetir o contextualizar resultados si procede, cronología, administración, posibles interacciones, fuentes oficiales vigentes y protocolos locales. No diagnostiques fracaso ni atribuyas causalidad a un dato aislado.
4. Si se solicitan interacciones, dosis o cambios terapéuticos, indica qué documentos oficiales y datos del caso se necesitan. No inventes recomendaciones, referencias o dosis. Distingue hipótesis de evidencia verificada.
5. Entrega una tabla con: dato disponible; dato que falta; por qué importa; fuente o verificación requerida. Termina con una lista breve de preguntas para la consulta y una nota sobre límites del análisis.

Este material es un guion docente, no una guía clínica validada ni un sistema de apoyo a la decisión. La revisión y cualquier decisión corresponden a profesionales en un entorno autorizado.
